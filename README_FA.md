# راهنمای اجرای Seq Lab

## اجرا
روی **Start-SeqLab.cmd** دوبار کلیک کنید.
برنامه در مرورگر، در نشانی http://127.0.0.1:8765 باز می‌شود.
برای استفادهٔ معمول اینترنت لازم نیست.

## شروع کار
۱. پروژهٔ آموزشی موجود را باز کنید یا New project را بزنید.
۲. با Import sequence توالی را وارhttp://127.0.0.1:8765/د کنید و نوع DNA، RNA یا Protein را مشخص کنید.
۳. پارامترها را تنظیم کنید و Run analysis را بزنید.
۴. نتایج در Overview، Translation، ORFs و Visualizations نمایش داده می‌شوند.
۵. نتایج به‌صورت خودکار ذخیره می‌شوند؛ سابقه در Analysis History است.
۶. از Reports یا دکمه‌های خروجی، نتایج را دریافت کنید.

مثال‌ها مصنوعی و آموزشی هستند، نه داده‌های زیستی مرجع.
برای نمونهٔ ATGAAATGA مقدار GC برابر ۲۲٫۲۲٪ است. برای این نمونه Window و Step را ۳ و حداقل طول ORF را ۶ بگذارید.

## قابلیت‌های این نسخه
ورود FASTA و متن توالی، اعتبارسنجی، تحلیل DNA/RNA و پروتئین، ترجمهٔ شش چارچوب، ORF، نمودار تعاملی، تبدیل و استخراج توالی، ذخیرهٔ پروژه، خروجی FASTA/CSV/JSON/HTML و PNG/SVG.
رابط انگلیسی و دارای تم روشن و تیره است.
این نسخه هستهٔ اولیهٔ قابل‌استفاده است؛ ابزارهای پیشرفتهٔ BLAST، MAFFT، Primer3، RNAfold و نصب‌کنندهٔ مستقل ویندوز هنوز پیاده‌سازی نشده‌اند.

## محل داده‌ها
همهٔ فایل‌های پروژه در E:\Projects\SeqLab قرار دارند.
پایگاه داده در پوشهٔ data است. برای پشتیبان‌گیری از فایل‌های پایگاه داده، ابتدا سرور را متوقف و سپس کل پوشهٔ data را کپی کنید.
بستن مرورگر، سرور را متوقف نمی‌کند. فایل Stop-SeqLab.ps1 برای توقف سرور آماده است؛ دستور دقیق در README.md است.
خروجی JSON پروژه فعلاً برای آرشیو است و ورود دوبارهٔ آن در رابط هنوز وجود ندارد.

## بررسی‌ها
۲۴ آزمون بک‌اند، ۳ آزمون رابط و ۲ سناریوی کامل مرورگر موفق شده‌اند.
جزئیات، محدودیت‌ها و مدارک آزمون در docs/VALIDATION.md و پوشهٔ artifacts قرار دارد.
