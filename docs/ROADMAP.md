# Release plan
## Delivered: 0.1 functional scientific core
Local project workflows, immutable sources, FASTA/raw input, nucleotide/protein science, interactive plots, derived sequences, history and exports.

## Phase 2: comparative bioinformatics
Validated pairwise alignment, MAFFT integration, alignment viewer, FASTQ QC and richer reports with figures.
## Phase 3: molecular analysis
Primer3, restriction digestion, ViennaRNA, NJ phylogeny from alignments, optional NCBI/BLAST.
## Phase 4: production desktop
Installer, managed sidecar, migrations, backup/import, first-run checks, large-data benchmarks, accessibility and localization.

No unavailable scientific engine is represented as operational. These phases have not been implemented in this delivery.

## Add a module
Define supported types, parameter/result schemas and method assumptions. Implement a pure scientific service or isolated validated tool adapter. Preserve hashes and versions. Add known-answer, invalid-input and integration tests. Expose a typed API and UI with exports. Verify the full workflow before enabling navigation.
